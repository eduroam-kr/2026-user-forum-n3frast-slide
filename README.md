## 이 자료에서 말하는 것

- 「CA 인증서 확인 안 함」 · TOFU 로 접속하면, 가짜 AP 에도 비밀번호를 넘길 수 있음
- 단말이 서버를 확인하려면 CA 인증서와 서버 이름이 필요함
- 웹용 공인 인증서는 RADIUS 에 맞지 않으며, 에듀롬 전용 사설 CA 를 권장함
- 참여기관은 CA 인증서와 지문을 안내 페이지에 공개할 의무가 있음 (운영약관)
- 안내 페이지에는 「대한민국 eduroam 서비스 및 상표 고지」를 게시함
- 다중캠퍼스는 RFC 5580 위치 속성으로 캠퍼스 · 건물을 RADIUS 기록에 남길 수 있음
- 국내 참여기관 서버 인증서 점검과 사전 설문 결과

## 보는 방법

브라우저로 위 슬라이드 주소를 엽니다. 키보드 화살표나 화면 아래 화살표로 넘깁니다.
내려받아 볼 때는 `index.html` 이 있는 폴더에서 로컬 웹 서버를 실행합니다.

```sh
python3 -m http.server 8000
# http://localhost:8000 접속
```

`index.html` 을 파일로 바로 열면(file://) 브라우저 보안 정책 때문에 일부 기능이 동작하지 않을 수 있습니다.
